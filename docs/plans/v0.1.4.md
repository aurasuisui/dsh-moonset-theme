# 0.1.4 计划：玻璃材质（三面）

> **目标**：给**侧栏、顶栏、输入卡**三面加玻璃材质（半透明 + 背景模糊 + 边缘高光），让 0.1.2 的地面光晕能从面后透出来；默认开、可关、模糊强度可调。
> **非目标**：不做菜单/弹层/对话框的材质（浮层留在后续）；不做动画；不改布局；不改主题注册、首帧注入、地面光晕、步骤行配色。
> **时点**：2026-11-24，`main` = `6300362`，npm latest = 0.1.3。

**版本判定**：PATCH（0.1.3 → 0.1.4），新增能力但不动既有接口契约。

## 一、技术方案（沿用 P1–P5，新增 P6/P7）

| # | 规则 | 理由 |
|---|---|---|
| **P6** | **材质画在 `::before`，容器本体零绘制** | `backdrop-filter` 会造 backdrop root；本体若也画，模糊只糊到自己 |
| **P7** | **只给「背后有地面」的三面加** | 地面之上的面加 blur 是恒等变换（catppuccin 实测 0/19184 像素差异），纯浪费 |

做法（每面一份）：

```css
html[data-moonset-skin][data-moonset-glass] <面> { position: relative; }
html[data-moonset-skin][data-moonset-glass] <面>::before {
  content: ''; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  background: color-mix(in srgb, var(--dsw-alias-bg-base) 62%, transparent);
  backdrop-filter: blur(var(--dsh-moonset-glass-blur)) saturate(1.15);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.10);
}
```

- 材质底 = 画布色 × 62%（暗色可调），**不写死 hex**；
- 模糊半径走 `--dsh-moonset-glass-blur`（默认 12px，设置里 0–30 可调）；
- 根属性 **`data-moonset-glass`** 独立门控（光晕关掉玻璃仍可在，但没可透内容，文档写明）；
- 三面选择器全部用**稳定属性**，待 M1/M2 实测确认（见 D1/D2）。

### 2.3 缺陷或风险台账

| ID | 风险 | 关闭条件 |
|---|---|---|
| **D1** | 顶栏归属未定 | 从 asar 确认真实 DOM，给 file:line；选择器不数超过 3 层 |
| **D2** | 输入卡承载元素未定（`[data-composer-seat]` 是座位，卡片是其子元素） | 同上 |
| **D3** | `backdrop-filter` 让容器成为 fixed 后代的包含块（**实测：宿主座位本来就有 `will-change: transform`，fixed 早已相对座位**，故判据改为「材质开/关落点一致」） | 探针：座位内放 `position:fixed;left:0;top:0` 方块，落点仍为视口原点；不合格则该面回退为「半透明色、不 blur」 |
| **D4** | 滚动时 backdrop-filter 逐帧重算 | 1s 采样，帧时长 <16.7ms 占比 ≥95%；不合格降 blur 或减面 |
| **D5** | 暗色材质过亮/过灰 | 深浅各一张截图；材质底与正文对比度 ≥4.5:1 |

## 八、已决与已知债

**已决**
1. 玻璃**默认开**（用户 2026-11-23 要求），可关。
2. 只做三面，**不做菜单/弹层**：浮层的 backdrop root 与固定定位耦合最深，留到后续评估。
3. 材质画在 `::before`（P6），`pointer-events: none`，不影响点击。

**已知债**
- 沿用 0.1.2：地面光晕的多面板串色是接受的。
- 时间戳、成功态、`上下文注入` 行的配色缺口维持 0.1.3 的结论。
