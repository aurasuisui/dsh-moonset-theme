# 0.1.3 计划：设置区可读性、选中行时间戳、轨迹终端配色

> **目标**：修掉两处「看得见但不对」的文字问题，并把消息流里的**工作步骤行**（代码 / 思考 / 读取 / 运行命令）改成终端配色。
> **非目标**：不做玻璃材质（0.1.4）；不做 README 大改（0.1.5）；不改光晕参数、不改主题注册与首屏注入。
> **时点**：2026-11-23，`main` = `7763e59`，npm latest = 0.1.2。

**版本判定**：PATCH（0.1.2 → 0.1.3）。

### 1.2 缺口

| # | 现象 | 根因（已定位） |
|---|---|---|
| G1 | 深色下设置区选中按钮**白底白字** | 本主题 section 的 active 态用 `--dsw-alias-brand-primary` 当底色，而该 token 在暗色下是**近白色**（官方语义是墨色），文字又用 `label-on-color`（白） |
| G2 | 选中会话行的**时间戳仍是灰** | 标题靠 `[aria-selected='true']` 继承变紫，但 `.meta` 自己写了 `label-tertiary`，继承被覆盖 |
| G3 | 工作步骤行没有终端感 | 目前只有继承色；`代码` / `思考` / `读取` / `运行命令` / `退出码` 没有各自色阶 |

### 1.3 台账

| ID | 风险 | 关闭条件 |
|---|---|---|
| **D1** | 时间戳元素可能没有稳定钩子（类名 hash） | 若无可用的 `time`/`data-*` 钩子，报告出来并按「结构选择器」方案单独评审，不硬写 |
| **D2** | 轨迹行钩子不明（`data-step-process-*`、`data-chat-flow-kind` 等已知存在） | 用安装态 asar 反查确认至少 3 类行的稳定属性 |
| **D3** | 给轨迹上色可能误伤正文 | 只对**步骤行容器**内的标签元素着色，正文 `p`/`code` 不受影响 |
