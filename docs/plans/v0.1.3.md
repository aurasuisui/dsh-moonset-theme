## 六、已决与已知债

**已决**
1. 轨迹配色属于皮肤层第 6 类（终端色阶），仍走「稳定属性 + 根属性门控」，不加 JS。
2. 色相按 **`data-variant`（闭集 8 个）** 分，不按 `data-tool`（开集，插件/MCP 会增长）：未知工具由宿主 `classifyTool()` 折进 `code`/`others`，天然有兜底色。
3. 色相通过自定义属性发布到行上（`--dsh-moonset-step-name/-args`），加一类 = 加一个声明块，格子规则不动。
4. 时间戳无钩子 → 用户同意不染，不做脆弱选择器。

- ~~选中会话行时间戳~~：**用户 2026-11-23 决定不染**，本债关闭（宿主确实无稳定钩子，`Rows.tsx:738` 是裸 `<span>`）。
