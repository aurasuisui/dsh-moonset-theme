# 0.1.2 计划：环境光晕（月晕 + 琥珀辉光）

> **目标**：给页面加一层"月落"氛围地面——低对比 wash + 两枚固定光斑（靛蓝月晕 + 琥珀暖光），**默认一打开就有感觉**，并可在设置里调强度与关闭。
> **非目标**：不做玻璃材质（0.1.3）；不做动画光斑；不改主题注册/首帧注入；不做轨迹步骤配色（0.1.4）。
> **时点**：2026-11-23，`main` = `775b70a`，npm 上 0.1.1 为 latest。

**版本判定**：PATCH（0.1.1 → 0.1.2）。

## 一、技术方案（沿用 P1–P5）

**做法**：把光晕写进**同一张注入样式表**（`skinCss()`），用 `html[data-moonset-skin] body { background: … }` 覆盖地面。零 JS、零动画、零新合成层。

- **wash**（常开）：`linear-gradient(165deg, accent 3%, transparent 60%)` 一类的低对比底，横向差异 ≤2/255（catppuccin #25 实测的安全范围）；
- **两枚光斑**（默认开）：`radial-gradient(ellipse at 50% -10%, indigo 16%, transparent 62%)` + `radial-gradient(ellipse at 92% 88%, amber 10%, transparent 60%)`；
- **强度**：一个 `--dsh-moonset-glow-strength` 系数（0–200%，默认 100%）**内联在 background 表达式里**——catppuccin 实测：权重若存进中间 custom property，Chromium 不重算，旋钮会"失灵"；
- **开关**：关 = 不输出这条 background 规则（不是 alpha=0，那样仍会参与合成）。

**已知代价（接受并量化）**：光斑固定视口 ⇒ 多面板各自读到不同切片（catppuccin #26 实测同一面板内 ΔRGB 12–21/255）。我们用更低 alpha 控制，并把验收口径定为**同一面板内上下采样 ΔRGB ≤ 8/255**。

## 五、砍尾顺序

**不可砍**：M1 的双光斑与 wash（这是"有感觉"的来源）；M2 的开关（用户可能要关）。
**可砍**（按序）：强度滑块（保留开关，强度写死 100%）→ M2 的持久化（会话内生效）。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 光斑串色 | 低 alpha + D1 采样；超阈值就降 alpha 或只留 wash |
| 滚动性能 | 纯背景渐变无合成层；D3 采样；必要时把光斑改成 only-top |
| 与玻璃叠加后糊成一片 | 0.1.3 做玻璃时再一起调（先有地面才有玻璃层次） |

## 八、已决与已知债

**已决**
1. 光斑默认**开**且「一打开就有感觉」（用户 2026-11-23 要求），用低 alpha 兼顾串色。
2. 强度系数**内联在 background**，不存中间变量（catppuccin 实测的 Chromium 失效问题）。
3. 光晕属于 P5 白名单第 2 类「地面渐变」，不是新机制。

**已知债**
- 轨迹步骤（代码/思考/搜索/运行命令）的终端配色排在 **0.1.4**，本版不做。
- 光斑固定视口的多面板观感差异是**接受**的，靠低 alpha 缓解。
