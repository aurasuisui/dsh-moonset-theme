## 一、技术决策（维护者授权由 agent 拍板，2026-11-23）

**总原则：性能优先、开启后常驻开销低、好维护。** 落成五条可验收的硬规则：

| # | 规则 | 为什么 |
|---|---|---|
| P1 | **零常驻 JS 循环**：不装 `requestAnimationFrame`/scroll/resize 监听做视觉；视觉全部是 CSS | 空闲 CPU 与滚动帧率都不受插件影响 |
| P2 | **单张注入样式表**：一个 `<style data-dsh-moonset-skin>`，按根属性 `html[data-moonset-skin]` 门控；关闭 = 摘属性 + 删表 | 卸载零残留；避免多表打架 |
| P3 | **blur 只加在「背后有内容」的面**：侧栏/顶栏/输入卡；地面之上面（纯色背景）不加 | catppuccin 实测：地面之上的面加 blur 像素差 0/19184，纯浪费 |
| P4 | **材质画在 `::before` 平面**，容器本体零绘制 | `backdrop-filter` 会造 backdrop root 并把容器变成 fixed 后代的包含块 |
| P5 | **token 优先，CSS 只补 token 表达不了的**：`::selection`、body 背景渐变、材质面 | 主题切换自动跟随，四套主题不用各写一份 |

### 三块能力的具体方案

**A. 选区与选中态（0.1.1）**
- 选中态改 token：`--dsw-specific-sidebar-nav-item-active` → `color-mix(accent 10%, canvas)`，`-active-accent` → accent 文字；
- 文本选区必须注入 CSS：`html body ::selection { background: color-mix(in srgb, var(--dsw-alias-brand-primary) 28%, transparent); color: var(--dsw-alias-label-primary); }`（≤ 20 行）；
- 这是 P5 的第一个例外，写进 `docs/architecture.md` 的「CSS 注入白名单」。

**B. 环境光晕（0.1.2）**
- 做法：`html[data-moonset-skin] body { background: <wash 渐变>, <indigo 光斑>, <amber 光斑> }`；全部由 token 混出，不写死颜色；
- **默认「一打开就有感觉」**：光斑 alpha 起步 0.16（indigo）/ 0.10（amber），提供 0–200% 强度变量 `--dsh-moonset-glow`，默认 100%；
- 加权表达式**必须内联在 `background` 里**（catppuccin 实测：存中间变量会不重算）；
- 光斑固定视口，接受「多面板各自读到不同切片」的已知观感，用低 alpha 控制；提供开关。

**C. 玻璃材质（0.1.3）**
- 默认开启，只做三面：侧栏、顶栏、输入卡；
- 每面一个 `::before`：`background: color-mix(base 72%, transparent)` + `backdrop-filter: blur(12px) saturate(1.15)` + 顶部 1px 内高光 + 外阴影；
- 与光晕联动：先有地面层次，玻璃才有可透内容（catppuccin #25 的数字：纯色地面下卡与地面 ΔRGB 仅 2/255）；
- 0.1.4 才考虑菜单/弹层（`[data-menu-material]` 座位 + 四个物理坑），可砍。
