# 0.1.1 计划：选中态与选区（真机修订版）

> **目标**：DSH 的「选中/激活」状态在**会话列表、设置、插件页、自动化任务**四处都是月落的淡紫底 + 紫字；正文选区是**文档站那种**紫（底 + 紫字），不是灰紫。
> **非目标**：不动玻璃/光晕（0.1.2/0.1.3）；不做全局 `[class*=active]` 覆盖；不改布局。
**版本判定**：PATCH（0.1.0 → 0.1.1），只做主题覆盖，不引入新能力。

> **时点**：2026-11-23，真机首验失败后重写；分支 `feat/0.1.1-selection`，已有 `720f42a`（基础设施）与 `d0b8826`（皮肤跟随 choice）。

## 一、真机首验结论（2026-11-23 用户实测）

| # | 现象 | 判定 |
|---|---|---|
| 1 | 会话列表选中行**仍是灰** | ❌ 我们只覆盖了 `sidebar-nav-item-active`，而会话行用的是别的 token |
| 2 | 设置项 / 插件页 / 自动化任务页选中态**都没变** | ❌ 同上 |
| 3 | 正文拖选**是紫色**但"不是网页的那种效果" | ⚠️ 底色对了，**文字没跟着变紫**（文档站是 `selection:text-indigo-700`） |
| 4 | 一个版本一个 plan 文档 | 本文件 |

## 二、根因（从安装态 app.asar 反查，不是猜的）

按「选择器里含 selected/active/aria-selected/data-active」反查各模块 CSS 的 `background: var(--dsw-…)`，命中分布：

| token | 命中数 | 典型座位 |
|---|---|---|
| `--dsw-alias-interactive-bg-hover` | **14** | `.rowActive`、`.badge[data-active]`、自动化任务 tab、会话行 |
| `--dsw-alias-interactive-bg-active` | 7 | `:active` 按压态 |
| `--dsw-alias-state-business-primary` | 4 | 激活 tab 的下划线（`.tabActive::after`） |
| `--dsw-alias-bg-module-platform` | 2 | `.cardActive`、`.selected` |
| `--dsw-alias-button-ghost-active-fill` | 2 | 时钟/日期选择器选中 |
| `--dsw-alias-button-primary-fill` | 2 | chip 选中 |
| `--dsw-specific-sidebar-nav-item-active` | 1 | **只有设置侧栏**（已覆盖，所以设置项那一处也没生效是别的原因，见下） |

⇒ 首验只改了一个座位，主座位是 `interactive-bg-hover`。

## 五、砍尾顺序

**不可砍**：M2 的 `interactive-bg-hover` 与选区文字色（这两个就是首验失败的两条主因）。
**可砍**（按序）：`border-selected` → `button-ghost-active-fill` → `bg-module-platform`。

## 六、修订方案（token 优先，仍守 P5）

新增 token 覆盖（走生成器的 `TOKEN_OVERRIDES`，不许手改生成物）：

| token | 目标值 |
|---|---|
| `--dsw-alias-interactive-bg-hover` | `color-mix(in srgb, var(--dsw-static-deepseek-500) 10%, var(--dsw-alias-bg-base))` |
| `--dsw-alias-interactive-bg-active` | 同族 16% |
| `--dsw-alias-bg-module-platform` | 同族 12% |
| `--dsw-alias-button-ghost-active-fill` | 同族 18% |
| `--dsw-alias-border-selected` | 同族 40% |

> `--dsw-alias-state-business-primary`（激活下划线，4 命中）**不需要覆盖**：本表里它已经是 `var(--dsw-static-deepseek-500/-400)`，即 accent 本色。

选区对齐文档站（`selection:bg-indigo-500/20 selection:text-indigo-700`）：

```css
html body ::selection {
  background: color-mix(in srgb, var(--dsw-static-deepseek-500) 22%, transparent);
  color: var(--dsw-static-deepseek-700);   /* 浅色 = #4338CA 同级 */
}
```
暗色块同一套，改用暗侧 accent 的浅一级。
