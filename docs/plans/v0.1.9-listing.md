# 上架计划：awesome-dsh-plugin 收录

> **目标**：让 Moonset 出现在 DSH 插件市场。市场的插件列表来自精选列表 `awesome-dsh-plugin`，
> 所以「上架」= 向那个仓库提一个新增 YAML 文件的 PR。
> **非目标**：不改插件运行时；不改 npm 包内容；不新增版本（结论见下）。
> **时点**：2026-11-26，`main` = `f7c64f2`，npm latest = `0.1.8`。

**版本判定**：**不新发版本**。收录只发生在对方仓库（`data/plugins/*.yml`），本项目一个字节都不用改；
`docs/listing.md` 也不进 npm 包（`files` 只含 `lib`/`assets`/根文档），所以 0.1.8 就是被收录的版本。

### 1.2 收录规则（从 `contributing.md` 抄的原话）

1. **一个插件一个文件**：`data/plugins/<owner>__<repo>.yml`，文件名必须与 `url` 推出的 slug 一致；
2. **`url`** 必须是 `https://github.com/owner/repo` 形状；
3. **`category`** 必须取自固定集合（我们要用 `theme`）；
4. **`description.en`** 必填、单行、以句号结尾；含 `: `（冒号+空格）时必须加引号，否则 YAML 解析失败；
5. `icon` / `tarball` 可选，`icon` 必须是 GitHub 图床上的**位图**（不收矢量），否则回退到作者头像；
6. **README 是生成的，禁止手工编辑**；提交前可跑 `npm ci && node scripts/generate-readme.mjs` 自查（跑的就是 CI 那套校验）；
7. 评审标准：能用 `dsh plugin add` 装上、描述属实、分类贴切、在维护中。

### 1.4 缺陷或风险台账

| ID | 风险 | 关闭条件 |
|---|---|---|
| **D1** | 描述被判定「不属实」而被打回 | 每条声明对应仓库内可查的证据；不写做不到的事（侧栏无玻璃、原生菜单不可主题化等**不写进描述**） |
| **D2** | 没有 `icon` 会让卡片用作者头像，观感一般 | 可选：在 `main` 上补 `assets/icon-180.png`（180×180 位图），再让 YAML 引用 raw 链接；不补则走回退，不影响收录 |
| **D3** | YAML 里出现未加引号的 `: ` | 描述里**不用**「Moonset: ...」这种句式，或整句加单引号；本地跑 `generate-readme.mjs` 验证 |
| **D4** | 提交后无人跟进，PR 长期挂着 | 记录在 `docs/listing.md`，合并后回来核对市场里能搜到 |

## 六、已决与已知债

**已决**
1. **不发新版本**：收录不需要改包；0.1.8 就是被收录的版本。
2. 分类用 `theme`（与 `dsh-catppuccin`、`dsh-neo-skin` 等同类条目一致）。
3. 描述**只写已实现的能力**，已知边界（侧栏无玻璃、原生菜单不可主题化、导航轨位移）不进列表描述——列表只有一句话的位置。

**已知债**
- 无 `icon` 时市场卡片显示作者头像（`D2`）。
- 收录 ≠ 背书：列表页有免责声明，我们不额外声明安全性。

## 七、提交文案（预定稿）

`data/plugins/aurasuisui__dsh-moonset-theme.yml`：

```yaml
url: https://github.com/aurasuisui/dsh-moonset-theme
name: aurasuisui/dsh-moonset-theme
category: theme
description:
  en: Light and dark themes covering all 228 --dsw-* tokens, plus a thin skin layer with ambient ground glow, frosted input card and conversation header, per-tool-type colours on work-step rows, and document-site surface colours. No resident JavaScript, no network access, no telemetry.
  zh: 覆盖全部 228 个 --dsw-* token 的浅/深双主题，外加一层轻皮肤：环境地面光晕、磨砂输入卡与会话顶栏、工作步骤行按类型分色、代码框与卡片的文档站表面色。零常驻 JS、不联网、无遥测。
```

> 备注：`en` 里刻意避开 `: `（冒号+空格），改用逗号，`D3` 从源头消掉。

```markdown
Adds one entry: Moonset, a light/dark theme pair for DeepSeek Harness.

- 228 `--dsw-*` tokens per scheme, registered through the official theme API
- Follow-system mode, first-paint injection (no flash), choice persistence
- Thin skin layer: ambient ground glow (3 scopes, per-scheme hue and strength),
  frosted input card + conversation header + Windows caption strip, per-tool-type
  colours on work-step rows, document-site surface colours for code blocks and file cards
- Zero resident JavaScript, no network access, no telemetry

Published on npm as `@aurasuisui/dsh-moonset-theme` (latest 0.1.8), MIT licensed,
installs with `dsh plugin add`.

Palette credit: the colours come from [unmbt/moonset-document](https://github.com/unmbt/moonset-document)
by [Wyatex](https://github.com/Wyatex), who allowed reuse.
```
