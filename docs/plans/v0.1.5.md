# 0.1.5 计划：五处观感修正

> **目标**：修 0.1.4 的观感遗留——代码块 banner 与 header 的间距、深色「已编辑文件」卡片配色、`上下文注入` 行无色、浅色失败色过艳、回合导航轨改成文档站的形态。
> **非目标**：不做浮层材质（0.1.6）；不改玻璃/光晕/主题注册；不做 README 大改（更后面）。
> **时点**：2026-11-24，`main` = `8ca8d2a`，npm latest = 0.1.4。

**版本判定**：PATCH（0.1.4 → 0.1.5）。

### 1.2 缺口（用户 2026-11-24 第二轮目视）

| # | 现象 | 已定位的线索 |
|---|---|---|
| G1 | 代码块 banner **没紧贴 header**，中间有一条距离 | 0.1.4 给 banner 设了 `top: var(--dsh-moonset-header-h)`，但滚动体同时有 `margin-top: -H`，两者叠加可能多让了 H |
| G2 | 深色下「已编辑 N 个文件」卡片是**黑灰**，不好看 | 该卡用 `--dsw-alias-bg-layer-1` 一类底；要换成文档站代码框的配色（`bg-layer-2` + `border-l2`） |
| G3 | `上下文注入` 行**没有颜色** | 该行没有 `data-variant`，但有 `data-context-source` / `data-context-summary` |
| G4 | 浅色下失败行**太红** | 现在用 `state-error-primary`（`#B31B3E`），要在浅色降饱和/降明度对比 |
| G5 | 回合导航轨要与**文档站**形态一致（细竖线 + 渐变 + 圆点） | 现轨道是宿主的 hash 类名，需先找稳定钩子 |

### 1.3 缺陷或风险台账

| ID | 风险 | 关闭条件 |
|---|---|---|
| **D1** | 导航轨无稳定钩子 | 反查 asar；若无，报告并给出「是否允许一条 `[class*=]` 例外」的建议，不擅自破规矩 |
| **D2** | 失败色调淡后对比度掉到 AA 以下 | 浅/暗各测一次 ≥4.5:1 |
| **D3** | 「已编辑文件」卡片换色可能波及同类卡片 | 限定在其容器内，不写全局 `bg-layer` 覆盖 |
