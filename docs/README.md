## 怎么读

1. 只是要用：读根 [README](../README.md)，看完就够。
2. 要改代码：先 [architecture.md](architecture.md)，再按改动点看
   [palette.md](palette.md)（改色）或 [compatibility.md](compatibility.md)（共存）。
3. 要审阅/复跑：每个文档的节末都有「证据」或「复核命令」，命令都可离线复现；
   [plans/v0.1.0.md](plans/v0.1.0.md) 是这些结论的原始出处。

## 证据口径

- 文档里的数字都写明**怎么重算**（命令、文件、测试名）。重算不出来的一律标
  「未验证」并指到 [backlog-v0.2.md](backlog-v0.2.md) 的对应条目。
- 0.1.0 的**真机复验已完成**（2026-11-22，桌面壳三态 + 状态行读数），证据是
  [plans/v0.1.0.md](plans/v0.1.0.md) 看板里 M7.1 那行与 [assets/previews/](../assets/previews/) 的三张截图；
  没有真机证据的条目仍按上面那条规则标注。
- 计划里的「已决」与「已知债」正文是冻结的，文档只做引用与展开，不改写它们。
