## 1. 一句话简介

> Moonset（月落）—— 为 DeepSeek Harness Web GUI 提供浅色 / 深色双主题，并附一层可独立开关的轻皮肤（选中态、环境光晕、工作步骤行配色、三面玻璃材质）。

## 2. 详细描述

Moonset 向官方主题系统注册 `moonset-light` 与 `moonset-dark` 两个主题定义，各自覆盖安装态桌面壳里
**228 个 `--dsw-*` 颜色 token**（取自 `design-platform.css`）。它补两个官方缺口：

1. **第三方主题 id 记不住** —— `setTheme(id)` 只把 `light`/`dark`/`system` 写进设置文档，第三方 id 只活在内存里，
   每次 `adopt()` 回声都会被文档值覆盖。插件自带持久化字段 + 运行时再断言解决。
2. **首帧闪** —— 客户端脚本加载前页面已画了官方画布。Host 半区注入一张首帧样式表，客户端接管后撤掉。

皮肤层与主题层**互相独立**：关掉皮肤只留纯配色，关掉主题皮肤也还在。整条链路**不联网、无遥测、无常驻 JS**。

## 3. 特性清单

| 分类 | 特性 |
|---|---|
| 主题 | 两个主题定义（各 228 键）；跟随系统；首帧不闪；容错注册；自带持久化；回声再断言 |
| 皮肤 | 选中态与文本选区；环境光晕（三档范围 / 深浅各一套色相与强度）；工作步骤行按类型分色；三面玻璃（输入卡 / 会话 header / Windows 标题条）；编辑卡、代码框、交付文件卡的表面色；回合导航轨染色 |
| 设置 | 一个独立设置区（`order: 40`，中英双语）；主题三态、地面范围三档、光晕开关与两组色相/强度、玻璃开关与模糊；状态行 |

## 5. 权限与外部访问

| 项 | 事实 |
|---|---|
| 网络访问 | **无**。不抓取、不上报、不检查更新。 |
| 遥测 / 统计 | **无**。 |
| 文件系统 | 只读自身包内文件（构建期）；运行时**不读写**用户文件。 |
| DOM 写入 | 只有三笔：`<html>` 上摘挂两个布尔属性（`data-moonset-skin` / `data-moonset-glass`）、写两个行内自定义属性（玻璃模糊半径、实测的会话 header 高度）、`<head>` 里增删一张自己的 `<style>`。 |
| 官方配置 | 只写插件自己的 volatile 字段；唯一例外是「跟随系统」语义需要把官方偏好设为 `system`（用户点该按钮时）。 |
| 常驻 JS | **无**。无事件监听、无 `requestAnimationFrame`、无 observer、无轮询；只有一次性的写防抖与样式表重建定时器。 |

## 8. 已知限制（上架时必须如实告知）

- **侧栏不做玻璃材质**（有意的取舍）。
- **标题条「应用 / 编辑」下拉不可主题化**：Electron/OS 原生菜单，不吃 CSS。
- **回合导航轨有 38 px 位移**：只在切换玻璃开关时可见，常开无跳动。
- **选中会话行的时间戳不染色**；**退出码 0 的成功态不额外上色**（宿主只在失败时渲染胶囊）。
- **没有真正的「文件蓝」**：228 键表无 `sky`/`cyan` 家族，文件类用与强调色同族差一档的 `deepseek-400`。
- 完整清单（含 macOS 未验证、多窗口不同步、1500 ms 窗口、`:root{color-scheme}` 未发等）见 [README「已知边界」](../README.md#已知边界)。
